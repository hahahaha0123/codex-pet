# Artwork and attribution

The silver-haired, mint-colored Xiao Ke character and its animation drawings were generated for this project using ImageGen. They are original project assets, not an official OpenAI character. The source atlases, PNG frames and exported GIFs are included under the project's MIT license.

- `assets/codex-sprites.png`: original six-pose character reference.
- `assets/animation-sheets/`: four generated atlases, each containing six frames for four actions.
- `assets/animations/`: cropped transparent frames.
- `GIF动作/`: sixteen looping GIFs, six frames per action.
- `assets/art-prompt.txt` and `assets/animation-prompts.txt`: generation prompts.

The initial interaction concept was inspired by a desktop companion example. Its character artwork and source files are not included here.

Windows, WPF and SQLite APIs are provided by the operating system. Pillow is an optional build dependency for GIF encoding and is not bundled with the application. Names and trademarks belong to their respective owners.
